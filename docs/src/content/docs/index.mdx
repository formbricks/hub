## What Hub Is For

Hub is the place where operational feedback becomes queryable product data. Send
NPS scores, survey answers, app reviews, support ratings, and other feedback
events into a single service, then serve that data to BI tools, internal
workflows, or customer-facing experiences.

## Built In

<Aside type="note">
  Hub already includes API-first capabilities for feedback operations: semantic
  search, webhooks, runtime OpenAPI specs at <code>/openapi.yaml</code> and{" "}
  <code>/openapi.json</code>, and a clean data model for analytics.
</Aside>

<details open>
  <summary>Feedback sources Hub can model</summary>
  <ul>
    <li>Survey responses from your app or website</li>
    <li>NPS, CSAT, CES, ratings, and open text feedback</li>
    <li>App Store, Google Play, Trustpilot, and other review platforms</li>
    <li>Support ticket feedback from tools like Intercom or Zendesk</li>
